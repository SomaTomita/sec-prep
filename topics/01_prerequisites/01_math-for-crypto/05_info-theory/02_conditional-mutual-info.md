# 02. 条件付きエントロピーと相互情報量

> 親: [README](./README.md) ｜ 前: [01 シャノンエントロピー](./01_entropy.md) ｜ 次: [03 完全秘匿とOTP](./03_perfect-secrecy-otp.md) ｜ 層: 基礎(Layer 1)

`X` 単独の不確かさは測れた。次に知りたいのは「**別の確率変数 `Y` を知ったあと**、
`X` の不確かさはどれだけ減るか」。これが条件付きエントロピーと相互情報量で、
暗号では「暗号文 `Y=C` を見た攻撃者は平文 `X=M` について何を知れるか」に直結する。

**この1ページで分かること**

- 「Y を知った後に残る X の不確かさ」＝条件付きエントロピー `H(X|Y)`
- 「Y を知ると X の不確かさがどれだけ減るか」＝相互情報量 `I(X;Y)`
- `I(X;Y) = 0` が「暗号文が平文について何も語らない」の数学的表現になること

---

## 定義

```
条件付きエントロピー:
H(X|Y) = -Σ_{x,y} P(x,y) · log2 P(x|y)     （Y を知った後の X の平均的な不確かさ）

相互情報量:
I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X)     （X と Y が共有する情報量）
```

- `H(X|Y) ≤ H(X)`: 情報は不確かさを増やさない（悪くても変わらない）。
- `I(X;Y) = 0` ⟺ `X` と `Y` は独立（`Y` を知っても `X` について何も分からない）。
- `I(X;Y) ≥ 0` は常に成立する。

`H(X)` は「Y を知って減る分」と「Y を知っても残る分」に分解できる:

```mermaid
flowchart LR
    HX["H(X)<br/>X の不確かさ全体"] --> I["I(X;Y)<br/>Y を知って減る分（共有情報）"]
    HX --> HXY["H(X|Y)<br/>Y を知っても残る分"]
```

---

## 計算例：2x2 同時分布

X, Y を共に2値（0 か 1）とし、次の同時確率表を使う。

| P(X, Y) | Y=0 | Y=1 | 周辺 P(X) |
|---|---|---|---|
| X=0 | 0.4 | 0.1 | 0.5 |
| X=1 | 0.1 | 0.4 | 0.5 |
| 周辺 P(Y) | 0.5 | 0.5 | 1.0 |

X と Y は「同じ値になりやすい」相関を持つ（対角が 0.4、非対角が 0.1）。

### H(X), H(Y)

周辺分布はどちらも `(0.5, 0.5)` なので、01 の公平コインの結果がそのまま使える。

```
H(X) = H(Y) = 1 bit
```

### H(X|Y)

まず条件付き確率を出す（`P(x|y) = P(x,y)/P(y)`）。

```
P(X=0|Y=0) = 0.4/0.5 = 0.8    P(X=1|Y=0) = 0.1/0.5 = 0.2
P(X=0|Y=1) = 0.1/0.5 = 0.2    P(X=1|Y=1) = 0.4/0.5 = 0.8
```

`Y=0` の枝も `Y=1` の枝も、内訳が `(0.8, 0.2)` で同じ形（対称な表なので当然）。

```
log2(0.8) ≈ -0.322,  log2(0.2) ≈ -2.322

H(X|Y=0) = H(X|Y=1) = -0.8·(-0.322) - 0.2·(-2.322) = 0.258 + 0.464 = 0.722 bit

H(X|Y) = P(Y=0)·H(X|Y=0) + P(Y=1)·H(X|Y=1) = 0.5·0.722 + 0.5·0.722 = 0.722 bit
```

### I(X;Y)

```
I(X;Y) = H(X) - H(X|Y) = 1 - 0.722 = 0.278 bit
```

### 逆向きでも確認: I(X;Y) = H(Y) - H(Y|X)

表が対称（X と Y を入れ替えても同じ表）なので `H(Y|X) = H(X|Y) = 0.722 bit`。

```
H(Y) - H(Y|X) = 1 - 0.722 = 0.278 bit   → 一致 ✓
```

`X` と `Y` は独立ではない（`I(X;Y) = 0.278 bit > 0`）ので、片方を知るともう片方の
不確かさが 0.278 bit だけ減る。

---

## 演習（解答つき）

1. 表から `P(Y=1|X=1)` を計算し、対称性から予想される値と一致するか確認せよ。
2. 同時エントロピー `H(X,Y) = -Σ P(x,y)·log2 P(x,y)` を上の表から計算し、
   `H(X,Y) = H(X) + H(Y|X)` が成り立つか検証せよ。
3. もし表の4マスがすべて 0.25（独立）だったら `I(X;Y)` はいくつになるか。

<details><summary>解答</summary>

1. `P(Y=1|X=1) = P(X=1,Y=1)/P(X=1) = 0.4/0.5 = 0.8`。本文の `P(X=1|Y=1) = 0.8` と
   対称性の通り一致する。
2. `H(X,Y) = -2·(0.4·log2 0.4) - 2·(0.1·log2 0.1)`
   `log2(0.4) ≈ -1.322`, `log2(0.1) ≈ -3.322`
   `= -2·0.4·(-1.322) - 2·0.1·(-3.322) = 1.058 + 0.664 = 1.722 bit`
   `H(X) + H(Y|X) = 1 + 0.722 = 1.722 bit` → 一致 ✓
3. 全マス独立（`P(x,y)=P(x)P(y)`）なら `H(X|Y)=H(X)` となり `I(X;Y) = 0 bit`
   （`Y` を知っても `X` の不確かさは変わらない）。

</details>

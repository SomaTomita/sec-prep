# 01. シャノンエントロピー — 予測しにくさの尺度

> 親: [README](./README.md) ｜ 次: [02 条件付きエントロピー・相互情報量](./02_conditional-mutual-info.md) ｜ 層: 基礎(Layer 1)

「鍵は何ビット必要か」「このパスワードはどれだけ強いか」に答えるには、
まず「不確かさ」を数値化する道具が要る。それが **シャノンエントロピー** H(X)。

---

## 定義

確率変数 `X` が値 `x_1, ..., x_n` を確率 `P(x_1), ..., P(x_n)` で取るとき、

```
H(X) = -Σ_i P(x_i) · log2 P(x_i)     [単位: ビット (bit)]
```

- `log2` を使うのは「1ビットで区別できる場合の数」を単位にするため。
- `P(x_i) = 0` の項は `0·log2 0 = 0` と約束する（極限で 0 に収束するため）。
- 直感: `H(X)` が大きいほど `X` の結果を **当てにくい**。全部同じ値しか出ないなら `H(X) = 0`。

---

## 計算例：3つのケース

### (a) 公平なコイン

`P(表) = P(裏) = 0.5`

```
H(X) = -0.5·log2(0.5) - 0.5·log2(0.5)
     = -0.5·(-1) - 0.5·(-1)
     = 0.5 + 0.5 = 1 bit
```

「表裏どちらが出るか」を伝えるのに **ちょうど1ビット** 必要、という意味。

### (b) 偏ったコイン（P(表) = 0.9）

`P(表) = 0.9, P(裏) = 0.1`

```
log2(0.9) ≈ -0.152,  log2(0.1) ≈ -3.322

H(X) = -0.9·log2(0.9) - 0.1·log2(0.1)
     = -0.9·(-0.152) - 0.1·(-3.322)
     = 0.137 + 0.332
     ≈ 0.469 bit
```

公平なコインより結果が予測しやすい（ほぼ表）ので、エントロピーは 1 bit より小さい。

### (c) 公平な8面ダイス

等確率 `P(x_i) = 1/8`（`i = 1..8`）

```
H(X) = -Σ_{i=1}^{8} (1/8)·log2(1/8) = -log2(1/8) = log2(8) = 3 bit
```

一般に、`n` 個が等確率なら `H(X) = log2(n)`（最大エントロピー）。

---

## 性質：0 ≤ H(X) ≤ log2(n)

- 下限 `0`: 結果が1つに確定している（不確かさゼロ）
- 上限 `log2(n)`: `n` 個の値が **等確率** のとき最大（一番当てにくい）
- 上の (a)(b)(c) はどれもこの範囲に収まっている

---

## パスワード・鍵の強度への接続

「鍵は128ビットのエントロピーを持つ」とは、鍵の分布が `H(K) = 128 bit` であること
——典型的には `2^128` 通りから一様ランダムに選ばれる状態を指す。逆に、パスワードが
辞書の単語1つ（候補1万語）なら `H ≈ log2(10000) ≈ 13.3 bit` しかなく、「128ビット鍵」
とは桁違いに弱い。ビット数がそのまま「総当たりの手間」に直結する話は
[04 鍵長と安全性](./04_key-length-security.md) で数値表を使って詰める。

---

## 演習（解答つき）

1. 4面ダイス（等確率）のエントロピー `H(X)` を求めよ。
2. `P(晴)=0.7, P(雨)=0.3` の天気予報のエントロピーを小数第3位まで求めよ。
3. コインが「必ず表」（`P(表)=1, P(裏)=0`）のとき `H(X)` はいくつか。理由も述べよ。

<details><summary>解答</summary>

1. 等確率4通り → `H(X) = log2(4) = 2 bit`。
2. `log2(0.7) ≈ -0.515`, `log2(0.3) ≈ -1.737`
   `H(X) = -0.7·(-0.515) - 0.3·(-1.737) = 0.360 + 0.521 = 0.881 bit`
3. `H(X) = 0`。`P(表)=1` の項は `1·log2(1) = 1·0 = 0`、`P(裏)=0` の項は約束により `0`。
   結果が確定しているので不確かさはゼロ。

</details>

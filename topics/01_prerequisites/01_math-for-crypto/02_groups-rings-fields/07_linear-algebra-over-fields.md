# 07. 有限体上の線形代数

> 親: [README](./README.md) ｜ 前: [06 有限体GF(2^n)とAES](./06_gf2n-and-aes.md) ｜ 層: 基礎(Layer 1)

`01`〜`06` で「体」まで来た。体の元を**成分**として並べたものがベクトルで、
ベクトルを別のベクトルに写す規則が行列である。暗号では、この単純な道具が
LFSR の解読からAESの拡散層、格子暗号の土台まで、繰り返し姿を変えて現れる。
本ファイルはその共通言語を用意する。

---

## 有限体の上にベクトルを載せる

実数上のベクトル空間の公理は、そのまま任意の体 `GF(q)` の上でも成り立つ。
**唯一の違いはスカラーが有限個（`q` 個）しかないこと**——加法・スカラー倍の性質、
一次独立・基底・次元の定義は一切変わらない。

`GF(2)ⁿ` は特に重要な例で、**n ビットのビット列そのもの**と一致する。

```
GF(2)^3 のベクトル: (1,0,1)
加算はビットごとの XOR:  (1,0,1) + (1,1,0) = (0,1,1)
スカラーは 0 と 1 だけ:  1·v = v,  0·v = 0
```

「ビット列の XOR」を線形代数として見る、というこの視点の転換が本ファイルの出発点になる。
`(1,0,0), (0,1,0), (0,0,1)` は `GF(2)³` の基底（次元3）であり、
`(1,1,0)` と `(0,1,1)` は互いの定数倍でないので一次独立——実数上の判定と同じ手順で確認できる。

---

## 行列は「線形層」そのもの

行列とベクトルの積は、成分の加算・乗算を体の演算に置き換えるだけで実数上と同じ形で定義できる。
これは暗号設計者にとって**具体的な意味**を持つ——

**ブロック暗号の線形層は行列積である。** `GF(2⁸)` 上の4×4行列は AES の MixColumns
そのものであり、`GF(2)` 上の置換行列はビットの並べ替えを表す
（[06](./06_gf2n-and-aes.md) の `GF(2⁸)` 演算がここでの係数になる）。

行列の合成は行列の積になる——**複数ラウンドの線形部分をまとめて1つの行列に圧縮できる**。
線形な処理だけをいくら重ねても、全体は依然として1つの行列でしかない。
S-box のような非線形部品が必要になる理由がここにある。

## 連立一次方程式を解く＝状態を復元する

`GF(q)` 上でも Gauss の消去法はそのまま動く——**割り算は逆元を掛けること**
（[`../01_modular-arithmetic/06_modular-inverse.md`](../01_modular-arithmetic/06_modular-inverse.md) の乗法逆元の計算がそのまま使える）。

実数上との決定的な違いは解の個数にある。連立方程式 `Ax = b` が解を持つとき、

```
解の個数 = q^(n − rank(A))
```

実数上なら「一意」か「無限個」の二択だが、**GF(q) 上では有限個**になる。
この違いが暗号の攻撃コストに直結する——LFSR の状態復元がその典型例である。

```
n ビットの LFSR の出力を n ビット観測する
  → 未知数 n 個（初期状態）に対して一次方程式が n 本立つ
  → rank が n なら解は一意 → 初期状態が確定 → 以降の全出力が予測できる
```

**線形であることが致命的な理由がこれ**——攻撃コストが総当たり `2ⁿ` から
連立方程式の求解（多項式時間）に落ちる。攻撃の詳細は
[`../../../02_cryptography/02_symmetric-crypto/01_stream-ciphers-and-lfsr.md`](../../../02_cryptography/02_symmetric-crypto/01_stream-ciphers-and-lfsr.md) が本体。

## MDS 行列と分岐数

線形層の「拡散の強さ」を測る指標が**分岐数**である。

```
分岐数 B(M) = 非零ベクトル x について、wt(x) + wt(Mx) の最小値
              （wt = 非零成分の個数）
```

`n` 次正方行列の分岐数は最大でも `n+1`。この最大値を達成する行列が
**MDS 行列**（Maximum Distance Separable）——符号理論から借りた概念で、
**すべての正方小行列式が非零であること**と同値な特徴づけを持つ。

分岐数が大きいほど、1成分の変化が出力の多くの成分に波及する——差分・線形解読で
辿れる「アクティブな成分数」の下界を分岐数が決める。AES の MixColumns は
4×4 の MDS 行列で、分岐数は最大値の **5**。なぜその行列を選んだかは
[`../../../02_cryptography/02_symmetric-crypto/03_aes-internals.md`](../../../02_cryptography/02_symmetric-crypto/03_aes-internals.md) が本体。

## 演習（解答つき）

1. `GF(2)³` のベクトル `(1,1,0)` と `(0,1,1)` は一次独立か。理由も述べよ。
2. 8ビットの LFSR の出力を8ビット観測したところ、立てた連立方程式の rank が 6 だった。
   初期状態の候補は何通りか。
3. ある4×4の線形変換の分岐数が2だった。この変換を暗号の拡散層に使うと何が問題か。

<details><summary>解答</summary>

1. 一次独立である。`GF(2)` 上でスカラーは `0` と `1` しかないため、一次従属になるのは
   一方が他方の定数倍（＝完全に一致する）場合のみ。`(1,1,0) ≠ (0,1,1)` なので独立。
2. `q^(n−rank) = 2^(8−6) = 2² = 4` 通り。rank が満杯（8）でないため解は一意に定まらず、
   観測データと矛盾しない初期状態が4通り残る。
3. 分岐数の理論上の最大値は `n+1 = 5` なので、2は非常に低い。ある入力で1成分だけ変えても
   出力側では高々1成分しか変わらない経路が存在しうるということであり、拡散が弱い。
   差分・線形解読でアクティブな成分数を少なく保てる経路が残ってしまい、
   攻撃者に有利な低確率でない差分特性・線形近似を許してしまう。

</details>

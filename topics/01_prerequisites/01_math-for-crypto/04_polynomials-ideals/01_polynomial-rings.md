# 01. 多項式環 F[x] とその演算

> 親: [README](./README.md) ｜ 次: [02 既約多項式](./02_irreducible-polynomials.md) ｜ 層: 基礎(Layer 1)

整数を mod n で扱ったように、多項式も「係数の世界 F」を決めれば同じように
足し算・掛け算・割り算ができる環になる。特に **GF(2)[x]**（係数が 0/1 で
加算が XOR）は AES や符号理論の土台であり、Magma 実習で最初に
手を動かす対象。ここでは加減乗と除算アルゴリズムを筆算で確認する。

**この1ページで分かること**

- 多項式も整数と同じように加減乗除ができ、環 `F[x]` をなすこと（整数 `Z` との対応表）
- 係数が 0/1・加算が XOR の `GF(2)[x]` の計算感覚（AES の土台）
- 整数の割り算と同じ形の除算アルゴリズム（商と余りの一意性）と筆算の手順

---

## 多項式環 F[x] の定義

```
F[x] = { a_n x^n + a_{n-1} x^{n-1} + ... + a_1 x + a_0 : a_i ∈ F, n ≥ 0 }

加算: 同じ次数の係数どうしを F の加算で足す
乗算: 分配法則で展開し、同じ次数の係数を F の加算で集める
      (係数の掛け算・足し算はすべて F の演算規則に従う)
```

`F` が体（加減乗除が自由にできる代数系、[../02_groups-rings-fields/05_fields-and-gfp.md](../02_groups-rings-fields/05_fields-and-gfp.md)。
体でなくても環でよいが、ここでは体を主に扱う）なら `F[x]` は可換環（掛け算の順序を
入れ替えられる環）になる。整数環 `Z` との対応関係が強力な道しるべになる:

| 整数環 `Z` | 多項式環 `F[x]` |
|---|---|
| 数の大きさ（絶対値） | 次数 `deg` |
| 素数 | 既約多項式（→ [02](./02_irreducible-polynomials.md)） |
| 除算 `a = q·b + r`（`0 ≤ r < b`） | 除算 `a(x) = q(x)·b(x) + r(x)`（`deg r < deg b`） |
| `Z/nZ`（`n` が素数なら体） | `F[x]/(f)`（`f` が既約なら体 → [03](./03_quotient-rings-gf2n.md)） |

`Z[x]`（整数係数の多項式環）も暗号で登場する — NTRU や Ring-LWE（いずれも格子ベースの
耐量子暗号）は `Z_q[x]/(x^n+1)` のような環の上で定義される（[04](./04_ideals-groebner-intro.md) で触れる）。

---

## GF(2)[x]: 係数が XOR になる多項式環

係数の集合が `{0, 1}` で、加算が **XOR**（`1+1=0`）になる特別な場合。
AES の内部演算はすべてこの上に構築されている。

```
加算の例: (x^2 + x + 1) + (x + 1)
        = x^2 + (1⊕1)x + (1⊕1)
        = x^2                       ← x の項と定数項が消える

乗算の例: (x + 1)(x + 1)
        = x^2 + x + x + 1
        = x^2 + (1⊕1)x + 1
        = x^2 + 1                   ← 中間の x 項が消える（2x = 0）
```

引き算は存在しない（正確には加算と同じ）: `GF(2)` では `a - b = a + b`。
これが後述の除算アルゴリズムで「引く」操作を単純な XOR にする。

---

## 多項式の除算アルゴリズム

整数の除算（`a = b·q + r`, `0 ≤ r < b`）と同じ形が多項式にもある。

```
任意の a(x), b(x) ∈ F[x]（b(x) ≠ 0）に対し、
  a(x) = q(x)·b(x) + r(x)      deg(r) < deg(b)
を満たす q(x), r(x) ∈ F[x] が一意に存在する。
```

手順は整数の筆算と同じ発想:
1. 最高次の項どうしを割って商の項を1つ決める
2. その項と除数を掛けて被除数から引く（GF(2) では XOR）
3. 余りの次数が除数の次数未満になるまで 1〜2 を繰り返す

---

## 計算例：GF(2)[x] での筆算

`x^3 + x + 1` を `x + 1` で割る。

```
          x^2  +  x
        ┌───────────────────
x + 1  │ x^3 + 0x^2 + x + 1

Step 1: 最高次 x^3 ÷ x = x^2 を商に立てる
        (x+1)·x^2 = x^3 + x^2
        引く(XOR): (x^3+0x^2+x+1) ⊕ (x^3+x^2) = x^2 + x + 1

Step 2: 最高次 x^2 ÷ x = x を商に立てる
        (x+1)·x = x^2 + x
        引く(XOR): (x^2+x+1) ⊕ (x^2+x) = 1

Step 3: 余り 1 の次数(0) < 除数の次数(1) → 終了
```

結果: `x^3 + x + 1 = (x+1)(x^2+x) + 1`

検算: `(x+1)(x^2+x) + 1 = x^3+x^2+x^2+x + 1 = x^3 + (1⊕1)x^2 + x + 1 = x^3+x+1` ✓
（余りが 0 でない＝ `x+1` は `x^3+x+1` を割り切らない。この事実は
[02](./02_irreducible-polynomials.md) の既約性判定で再利用する。）

## 演習（解答つき）

1. GF(2)[x] で `(x^2+1) + (x^3+x+1)` を計算せよ。
2. GF(2)[x] で `(x+1)(x^2+x+1)` を展開せよ。
3. GF(2)[x] で `x^3+x^2+1` を `x+1` で割り、商と余りを求めよ。

<details><summary>解答</summary>

1. 係数を XOR: `x^3 + (0⊕1)x^2 + x + (1⊕1) = x^3 + x^2 + x`
2. `x^3+x^2+x + x^2+x+1 = x^3 + (1⊕1)x^2 + (1⊕1)x + 1 = x^3 + 1`
   （これは `x^3+1 = (x+1)(x^2+x+1)` という有名な因数分解に一致する）
3. `x^3+x^2+1 = (x+1)·x^2 + 1`。
   `(x+1)·x^2 = x^3+x^2`、引くと `(x^3+x^2+1)⊕(x^3+x^2) = 1`（次数0 < 1 で終了）。
   商 `x^2`、余り `1`。

</details>

## 次への接続

`x+1` で割ったときに余りが 0 にならない多項式（上の例の `x^3+x+1`）は、
「小さい次数の多項式の積に分解できない」候補になる。
これを体系的に判定するのが次の概念 **既約多項式**。
→ [02 既約多項式](./02_irreducible-polynomials.md)

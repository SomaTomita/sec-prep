# 04. 最大公約数とユークリッドの互除法

> 親: [README](./README.md) ｜ 前: [03 演算規則](./03_congruence-arithmetic.md) ｜ 次: [05 拡張ユークリッド](./05_extended-euclidean.md) ｜ 層: 基礎(Layer 1)

**この1ページで分かること**

- gcd（最大公約数）と「互いに素」の定義、lcm との関係
- ユークリッドの互除法の仕組み・正しさ・計算量 O(log min(a, b))
- 減算版の互除法と、それが定数時間 GCD（サイドチャネル対策）へ繋がる理由

合同式で「割り算（逆元）」ができるかどうかは **gcd = 1（互いに素）** で決まる。
その gcd を高速に求めるのが **ユークリッドの互除法**。逆元・RSA 鍵生成の前提になる。

---

## 最大公約数 gcd

`gcd(a, b)` … `a` と `b` の両方を割り切る正の整数のうち最大のもの。
言葉を分解すると「**約数**（割り切る数）→ **公約数**（両方に共通の約数）→ その**最大**」。

具体例として 15 と 10:
- 15 の約数: `1, 3, 5, 15`
- 10 の約数: `1, 2, 5, 10`
- 公約数（共通）: `1, 5` → 最大は **5** なので `gcd(15, 10) = 5`

- `gcd(12, 18) = 6`
- `gcd(7, 1) = 1`、`gcd(a, 0) = a`（0 は任意の数の倍数）

**互いに素（coprime）**: `gcd(a, b) = 1`。共通の素因数を持たない状態。
逆元の存在条件（[06](./06_modular-inverse.md)）であり、RSA で `e` と `φ(n)` に課す条件でもある。

### 最小公倍数 lcm との関係

gcd の相棒が **最小公倍数 lcm**（両方の倍数のうち最小）。両者は次で結ばれる:

```
lcm(a, b) = (a · b) / gcd(a, b)
```

例: `lcm(4, 6) = 4·6 / gcd(4,6) = 24 / 2 = 12`。

**RSA での出番**: 秘密指数 `d` を作る法として、実装では `φ(n) = (p−1)(q−1)` の代わりに
`λ(n) = lcm(p−1, q−1)`（カーマイケル関数、FIPS 186）を使うことが多い。`λ(n) | φ(n)` なので
より小さい指数で済む。どちらを法に取っても `d` は正しく機能する（正しさの証明は `../../../02_cryptography/` の RSA 本体）。

## ユークリッドの互除法

素因数分解せずに gcd を求めるアルゴリズム。核心は次の等式:

```
gcd(a, b) = gcd(b, a mod b)        （b > 0）
gcd(a, 0) = a                       （停止条件）
```

「大きい数を小さい数で割り、余りで割る数を置き換える」を余りが 0 になるまで繰り返す。
**最後に 0 でない余り（＝ 0 になる直前の割る数）が gcd。**

### なぜ成り立つか

`a = b·q + r`（`r = a mod b`）と書くと、

- `a, b` の公約数は `r = a − b·q` も割り切る → `(b, r)` の公約数でもある。
- 逆に `b, r` の公約数は `a = b·q + r` も割り切る → `(a, b)` の公約数でもある。

つまり `(a, b)` と `(b, r)` の公約数の集合は完全に一致するので、最大公約数も等しい。∎

### 擬似コード（実装の形）

```text
# 除算版（再帰）— 実装で最も一般的
gcd(a, b):
    if b == 0: return a
    return gcd(b, a mod b)
```

「余りで割る数を置き換えて自分自身を呼ぶ」だけ。停止条件は `b == 0`。

## 計算例

### `gcd(48, 18)`

```
48 = 18·2 + 12     gcd(48,18) = gcd(18,12)
18 = 12·1 +  6     gcd(18,12) = gcd(12, 6)
12 =  6·2 +  0     gcd(12, 6) = gcd( 6, 0) = 6
```
→ **gcd(48, 18) = 6**

余りの列 `12 → 6 → 0`。0 になる直前の `6` が答え。

### `gcd(629, 481)` — 約数が見えない数でも一発

```
629 = 481·1 + 148     gcd(629,481) = gcd(481,148)
481 = 148·3 +  37     gcd(481,148) = gcd(148, 37)
148 =  37·4 +   0     gcd(148, 37) = gcd( 37, 0) = 37
```
→ **gcd(629, 481) = 37**（素因数分解では一目で分からない例。互除法ならわずか 3 ステップ）

最後の行で `148` が `37` で割り切れる＝ `37` は `148` の約数。
そして `37` 自身の最大の約数は `37` なので、これが両者の最大公約数になる。

---

## 計算量

各ステップで余りは少なくとも半分以下に近づくため、ステップ数は
**O(log min(a, b))**。最悪ケースは連続するフィボナッチ数（ラメの定理）。
数千桁の数でも一瞬で終わるので、RSA 鍵生成で実用上問題にならない。

---

## 減算版の互除法（除算 ＝ 反復減算）

割り算の代わりに **引き算** でも gcd は求まる。

```
gcd(a, b) = gcd(b, a − b)     （a > b）
```

大きい方から小さい方を引き、大小が入れ替わったらまた大きい方から引く、を繰り返す。
両者が等しくなったら、その値が gcd。

**除算版と本質的に同じ理由**: 除算は「大小が入れ替わるまでの引き算」を 1 回でまとめているだけ。
`gcd(25, 10)` で並べると:

- 除算版: `25 = 10·2 + 5`（商 2・余り 5）→ `10 = 5·2 + 0` → gcd 5
- 減算版: `25−10=15`, `15−10=5`（10 を **2 回**引いた ＝ 商 2、残り 5）→ `10−5=5`, `5−5=0` → gcd 5

「商」＝「何回引けるか」、「余り」＝「引き切った残り」。両者は同じ計算で、
除算版の方がステップ数は圧倒的に少ない（`gcd(629,481)` は除算 3 ステップ／減算は 8 回引く）。

```text
# 減算版（反復）— 除算命令を使わない。正の整数を仮定
gcd_sub(a, b):
    while a != b:
        if a > b: a = a - b
        else:     b = b - a
    return a
```

### なぜ実装セキュリティで効くか（暗号実装・サイドチャネル）

減算版は単なる別解ではなく、実装セキュリティで重要な 2 つの話に繋がる。

- **二進 GCD（Stein のアルゴリズム）**: 減算と「2 で割る＝右シフト」だけで gcd を計算し、
  コストの高い多倍長除算を避ける。暗号ライブラリの高速化に使われる。
- **定数時間 GCD / 逆元**: 通常の互除法はステップ数や分岐が入力に依存するため、
  秘密値（RSA の鍵、ECDSA の nonce＝署名ごとに使い捨てる乱数、など）に適用すると
  **タイミング・サイドチャネル**（実行時間の違いという物理的な観測から秘密が漏れる経路）で漏れうる。
  これを防ぐ定数時間アルゴリズム（例: Bernstein–Yang の *safegcd*）が実装で使われる。
  → 暗号実装・サイドチャネル（HW セキュリティ）と直結。詳細は `deep/constant-time-gcd/`。

## 演習（解答つき）

ユークリッドの互除法で求めよ。

1. `gcd(252, 105)`
2. `gcd(1071, 462)`
3. `35` と `12` は互いに素か。

<details><summary>解答</summary>

1. `252 = 105·2 + 42` → `105 = 42·2 + 21` → `42 = 21·2 + 0` → **gcd = 21**
2. `1071 = 462·2 + 147` → `462 = 147·3 + 21` → `147 = 21·7 + 0` → **gcd = 21**
3. `35 = 12·2 + 11` → `12 = 11·1 + 1` → `11 = 1·11 + 0` → gcd = 1 → **互いに素**

</details>

## 暗号での出口

- **逆元の存在**: `a` が `mod n` で逆元を持つ ⟺ `gcd(a, n) = 1`（[06](./06_modular-inverse.md)）。
- **RSA 鍵生成**: 公開指数 `e` は `gcd(e, φ(n)) = 1` を満たすよう選ぶ。
- 互除法を「係数つき」に拡張すると、gcd だけでなく逆元そのものが求まる → 次。

---

## 次への接続

互除法を逆にたどると `a·x + b·y = gcd(a, b)` の整数解が得られる（ベズーの等式）。
これが逆元計算の正体。
→ [05 拡張ユークリッドの互除法](./05_extended-euclidean.md)

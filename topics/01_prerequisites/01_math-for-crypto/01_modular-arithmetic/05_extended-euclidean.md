# 05. 拡張ユークリッドの互除法とベズーの等式

> 親: [README](./README.md) ｜ 前: [04 gcd・ユークリッド互除法](./04_gcd-euclidean.md) ｜ 次: [06 逆元](./06_modular-inverse.md) ｜ 層: 基礎(Layer 1)

**この1ページで分かること**

- ベズーの等式 `a·x + b·y = gcd(a, b)` が必ず整数解を持つこと
- 互除法を逆にたどる（後退代入）で `x, y` を具体的に求める手順
- 一次不定方程式 `a·x + b·y = c` が解けるかどうかの条件と一般解

ユークリッドの互除法は gcd を返す。これを**逆にたどる**と、gcd を
`a·x + b·y` の形で表す整数 `x, y` まで分かる。これが逆元計算（[06](./06_modular-inverse.md)）の正体。

---

## ベズーの等式

任意の整数 `a, b`（ともに 0 でない）に対し、

```
a·x + b·y = gcd(a, b)
```

を満たす整数 `x, y` が **必ず存在する**。これを **ベズーの等式（Bézout's identity）** と呼ぶ。
拡張ユークリッドの互除法は、その `x, y` を具体的に求めるアルゴリズム。

---

## 求め方：割り算の式を逆にたどる（後退代入）

互除法で出てきた各ステップ `余り = 被除数 − 除数·商` を、**下から順に代入** して
余りを `a, b` の組み合わせに書き換えていく。

### 例: `35·x + 15·y = gcd(35, 15)` を解く

**前進（互除法で gcd を出す）**
```
35 = 15·2 + 5
15 =  5·3 + 0      → gcd = 5
```

**後退（余り 5 を 35, 15 で表す）**
```
5 = 35 − 15·2
```
これで完成。`x = 1, y = −2`:
```
35·1 + 15·(−2) = 35 − 30 = 5   ✓
```

### 例: もう一段深い `17·x + 5·y = 1`

**前進**
```
17 = 5·3 + 2
 5 = 2·2 + 1
 2 = 1·2 + 0      → gcd = 1
```
**後退**（一番下の非ゼロ余り `1` から始め、上の式で順に置換）
```
1 = 5 − 2·2
  = 5 − (17 − 5·3)·2          ← 2 = 17 − 5·3 を代入
  = 5 − 17·2 + 5·6
  = 5·7 − 17·2
```
→ `17·(−2) + 5·7 = −34 + 35 = 1`、つまり `x = −2, y = 7`。✓

> 手計算の機械化は深掘り候補 → `deep/extended-euclidean/`。

## 一次不定方程式 `a·x + b·y = c`

一次不定方程式＝**整数解だけ**を探す1次方程式。ベズーの等式の応用で、整数解を持つかどうかは gcd で決まる。

```
a·x + b·y = c が整数解を持つ ⟺ gcd(a, b) が c を割り切る
```

**解き方**: `g = gcd(a, b)` とし、拡張ユークリッドで `a·x₀ + b·y₀ = g` を得る。
`g | c` なら両辺を `c/g` 倍して特殊解を作り、一般解は

```
x = (c/g)·x₀ + (b/g)·t
y = (c/g)·y₀ − (a/g)·t        （t は任意の整数）
```

### 例: `35·x + 15·y = 10`

`g = gcd(35,15) = 5`、`5 | 10` なので解あり。上で得た `35·1 + 15·(−2) = 5` を 2 倍:
```
35·2 + 15·(−4) = 10            → 特殊解 x₀=2, y₀=−4
```
一般解（`b/g = 3`, `a/g = 7`）:
```
x = 2 + 3t,   y = −4 − 7t
```

## 演習（解答つき）

1. 拡張ユークリッドで `240·x + 46·y = gcd(240, 46)` を解け。
2. `6·x + 4·y = 7` は整数解を持つか。

<details><summary>解答</summary>

**1.** 前進:
```
240 = 46·5 + 10
 46 = 10·4 + 6
 10 =  6·1 + 4
  6 =  4·1 + 2
  4 =  2·2 + 0     → gcd = 2
```
後退:
```
2 = 6 − 4
  = 6 − (10 − 6)        = 2·6 − 10
  = 2·(46 − 10·4) − 10  = 2·46 − 9·10
  = 2·46 − 9·(240 − 46·5) = 47·46 − 9·240
```
→ `240·(−9) + 46·47 = −2160 + 2162 = 2`。**x = −9, y = 47**。

**2.** `gcd(6, 4) = 2`。`2` は `7` を割り切らない → **整数解なし**。

</details>

`a·x ≡ 1 (mod n)`。この `x` こそ `a` の **逆元**。

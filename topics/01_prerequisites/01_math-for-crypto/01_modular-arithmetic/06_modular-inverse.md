# 06. 逆元（Modular Inverse）

> 親: [README](./README.md) ｜ 前: [05 拡張ユークリッド](./05_extended-euclidean.md) ｜ 次: [07 中国剰余定理（入口）](./07_crt-intro.md) ｜ 層: 基礎(Layer 1)

合同式では割り算が一般にできない（[03](./03_congruence-arithmetic.md)）。
その代わりに「**掛けると 1 になる相手＝逆元**」を掛けることで「割る」を実現する。
RSA の秘密鍵はまさにこの逆元。

---

## 定義

法 `n` のもとで、整数 `a` に対し

```
a·x ≡ 1  (mod n)
```

を満たす `x` を `a` の **逆元** と呼び、`a⁻¹ (mod n)` と書く。
「`a` で割る」＝「`a⁻¹` を掛ける」と読み替えられる。

### 例

```
3⁻¹ ≡ 5  (mod 7)     なぜなら 3·5 = 15 ≡ 1 (mod 7)
```

---

## 存在条件

```
a が mod n で逆元を持つ  ⟺  gcd(a, n) = 1（a と n が互いに素）
```

**理由**: `a·x ≡ 1 (mod n)` は `a·x + n·y = 1` という一次不定方程式（[05](./05_extended-euclidean.md)）と同値。
これが整数解を持つのは `gcd(a, n) | 1`、すなわち `gcd(a, n) = 1` のときだけ。

逆元が **存在しない** 例: `gcd(4, 6) = 2 ≠ 1` なので `4⁻¹ (mod 6)` は存在しない。
（`4·x` は常に偶数で、`mod 6` で 1（奇数）になれない。）

---

## 求め方：拡張ユークリッド

`gcd(a, n) = 1` のとき、拡張ユークリッドで `a·x + n·y = 1` を解き、`x` を `mod n` に直す。

### 例: `3⁻¹ (mod 7)`

```
7 = 3·2 + 1
3 = 1·3 + 0          → gcd = 1
後退: 1 = 7 − 3·2     → 3·(−2) + 7·1 = 1
```
→ `3⁻¹ ≡ −2 ≡ 5 (mod 7)`。検算 `3·5 = 15 ≡ 1`。✓

### 例: `17⁻¹ (mod 5)`

[05](./05_extended-euclidean.md) の `17·(−2) + 5·7 = 1` を `mod 5` で見ると `17·(−2) ≡ 1`。
→ `17⁻¹ ≡ −2 ≡ 3 (mod 5)`。検算 `17 ≡ 2`, `2·3 = 6 ≡ 1`。✓

> 法 `n` が **素数** なら、`1 ≤ a < n` の全ての `a` が逆元を持つ。
> フェルマーの小定理を使うと `a⁻¹ ≡ aⁿ⁻² (mod n)` でも計算できる
> （詳細・証明は `../03_number-theory/02_fermat-little-theorem.md`）。

---

## なぜ「割り算」がこれで実現できるか

合同式で `a·z ≡ b (mod n)` から `z` を求めたいとき、両辺に `a⁻¹` を掛ける:

```
a⁻¹·a·z ≡ a⁻¹·b   →   z ≡ a⁻¹·b  (mod n)
```

これが「`b` を `a` で割る」に相当する。逆元が存在しない `a` では割れない、
というのが [03](./03_congruence-arithmetic.md) で「割り算は別扱い」とした理由。

---

## 演習（解答つき）

1. `5⁻¹ (mod 11)`
2. `7⁻¹ (mod 26)`
3. `8⁻¹ (mod 12)` は存在するか。

<details><summary>解答</summary>

1. `5·9 = 45 = 44 + 1 ≡ 1 (mod 11)` → `5⁻¹ ≡ **9**`。
2. `7·15 = 105 = 4·26 + 1 ≡ 1 (mod 26)` → `7⁻¹ ≡ **15**`（アフィン暗号で頻出）。
3. `gcd(8, 12) = 4 ≠ 1` → **存在しない**。

</details>

---

## 暗号での出口：RSA の秘密鍵

RSA では公開指数 `e` から秘密指数 `d` を

```
d ≡ e⁻¹  (mod φ(n))
```

として求める（`d·e ≡ 1 (mod φ(n))`）。`gcd(e, φ(n)) = 1` を満たすよう `e` を選ぶ（[04](./04_gcd-euclidean.md)）のは、
この逆元 `d` が存在するためだった。計算は拡張ユークリッドそのもの。

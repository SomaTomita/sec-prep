# 01. 格子と基底

> 親: [README](./README.md) ｜ 次: [02 SVP と CVP](./02_hard-problems-svp-cvp.md) ｜ 層: 基礎(Layer 1)

[`../02_groups-rings-fields/07_linear-algebra-over-fields.md`](../02_groups-rings-fields/07_linear-algebra-over-fields.md)
で見たベクトル空間は、係数が体の元だった。**係数を整数に制限すると**、連続だった空間が
「点の集合」に変わる。この一手で、Gauss 消去で瞬時に解けていた問題が急に難しくなる。

---

## 格子の定義

```
一次独立な n 本のベクトル b₁, ..., bₙ ∈ R^n が与えられたとき、
それらの整数係数の線形結合全体を格子と呼ぶ:

  L(B) = { c₁b₁ + c₂b₂ + ... + cₙbₙ : c₁,...,cₙ ∈ Z }
```

`b₁,...,bₙ` を**基底**、まとめた行列 `B` を基底行列と呼ぶ。一次独立の定義自体は
[`../02_groups-rings-fields/07_linear-algebra-over-fields.md`](../02_groups-rings-fields/07_linear-algebra-over-fields.md) と同じ——
本ファイルが変えるのは係数を**実数から整数へ**制限する点だけである。

**実数係数ならベクトル空間（連続、稠密）、整数係数なら格子（離散、飛び飛びの点）**——
この対比が格子暗号のすべての出発点になる。

---

## 同じ格子、違う基底

```
良い基底: 短く、互いにほぼ直交するベクトルの組
悪い基底: 長く、互いに鋭角に近いベクトルの組
```

同じ格子は複数の基底で張れる。2つの基底 `B, B'` が同じ格子を張るのは、
**ユニモジュラ行列**（成分が整数で行列式が `±1` の正方行列）`U` を使って
`B' = BU` と書けるとき、かつそのときに限る。

```
格子の点（●）は基底によらず同じ:
  ●   ●   ●   ●
  ●   ●   ●   ●
  ●   ●   ●   ●

良い基底: 短い2本の矢印がほぼ直角に交わる
悪い基底: 長い2本の矢印が鋭角で交わる（同じ点集合を張るが扱いにくい）
```

**これが暗号のトラップドアの源になる**——同じ格子について、
**良い基底を秘密鍵、悪い基底（から作った公開基底）を公開鍵**にできる。
悪い基底だけから格子の点を効率よく扱うのが難しいことが、次ファイルの困難性と直結する。

---

## 基底によらない不変量：行列式

基底の選び方は無限にあるが、**行列式（基本領域の体積）は基底の取り方によらない**——

```
det(L) := |det(B)|
```

`B' = BU`（`U` はユニモジュラ、`|det(U)|=1`）のとき `|det(B')| = |det(B)|·|det(U)| = |det(B)|`
なので、どの基底を選んでも同じ値になる。**「基底が変わっても変わらないもの」を
持つことが、格子を理論的に扱う足場になる。**

---

## 逐次最小：最短ベクトルの長さ

```
λ₁(L) := 格子 L の非零ベクトルのうち、長さが最小のものの長さ
```

`λ₁` は基底に依存しない格子自身の性質であり、これを**見つける**問題——
最短ベクトル問題（SVP）——が次ファイルの主役になる。

---

## 演習（解答つき）

1. `Z²`（整数座標平面）の基底を2通り挙げ、両方が同じ格子を張ることを確認せよ。
2. 基底 `B` と、行列式が `2` の整数行列 `M` について、`BM` は元の格子と同じ格子を張るか。
3. 「良い基底」と「悪い基底」があるとき、与えられた点に近い格子点を探す作業の
   難しさはどう違うか、直感で述べよ。

<details><summary>解答</summary>

1. 例: `B = {(1,0),(0,1)}` と `B' = {(1,1),(0,1)}`。`B' = BU`（`U = [[1,0],[1,1]]`,
   `det(U)=1`）なのでユニモジュラ変換であり、同じ格子 `Z²` を張る。
2. 張らない。ユニモジュラ行列（行列式 `±1`）でなければ格子は変わる——
   `det(BM) = det(B)·det(M) = 2·det(B)` となり、元の格子よりも「粗い」
   （点の間隔が広い）別の格子になる。
3. 良い基底（短く直交に近い）なら、各基底ベクトルの整数倍を四捨五入するだけで
   近い格子点にほぼ辿り着ける。悪い基底（長く鋭角）では、その素朴な丸め方が
   大きく外れることがあり、正しい格子点を探すには基底を作り直す（簡約する）か
   高コストな探索が必要になる。

</details>

# 02. SVP と CVP

> 親: [README](./README.md) ｜ 前: [01 格子と基底](./01_lattices-and-bases.md) ｜ 次: [03 LWE と SIS](./03_lwe-and-sis.md) ｜ 層: 基礎(Layer 1)

格子の点は無限に、しかも規則正しく並んでいる。それでも「一番短いものを探す」
「与えられた点に一番近いものを探す」のは驚くほど難しい。この難しさが格子暗号の土台になる。

---

## SVP：最短ベクトル問題

```
Shortest Vector Problem（SVP）:
  格子 L の非零ベクトルのうち、最も長さが短いもの（λ₁(L) を実現するベクトル）を求めよ
```

暗号で扱うのは主に**近似版 γ-SVP**——「`λ₁` の `γ` 倍以内の長さのベクトルを求めよ」
という緩和版である。`γ` を大きくするほど問題は易しくなる。

**厳密版 SVP は（ランダム化還元のもとで）NP困難であることが知られている**
（Ajtai, 1998）が、暗号が実際に安全性の根拠にする**多項式近似率の近似版は
NP困難であるとは知られていない**——大きな近似率では `NP∩coNP` に属することが
分かっており、NP困難だとむしろ考えにくい。**「NP困難だから安全」という単純化はできない**——
格子暗号の安全性は「効率的なアルゴリズムが知られていない」という**別の経験的信頼**に立つ。

---

## CVP：最近ベクトル問題

```
Closest Vector Problem（CVP）:
  格子 L 上にない点 t が与えられたとき、t に最も近い格子点を求めよ
```

SVP が「原点から最短の非零点」を探すのに対し、CVP は「任意の点から最短距離の格子点」を
探す、より一般的な問題。SVP は CVP の特殊ケースとみなせ、CVP を解ければ SVP も解ける。

---

## なぜ次元が上がると難しくなるのか

2次元なら図を描けば最短ベクトルは目で分かる。だが**次元が上がるにつれて
候補が爆発的に増え**、512次元のような暗号で使う規模では直感も総当たりも効かない。

```
良い基底があれば: 基底ベクトルを丸めるだけで SVP/CVP に近い答えが出る（01 参照）
悪い基底しかなければ: まず「良い基底を作る」こと自体が難しい問題になる
```

---

## 基底簡約：LLL と BKZ

**基底簡約**とは、悪い基底から出発して**より短く直交に近い基底を作り直す**アルゴリズムである。

```
LLL（Lenstra–Lenstra–Lovász, 1982）:
  多項式時間で動くが、得られる近似率は次元に対して指数的（2^O(n)）——弱い近似しか出ない

BKZ（blockwise Korkine–Zolotarev）:
  ブロックサイズ β を大きくするほど良い近似が得られるが、計算コストも増える
  「近似の質」と「計算時間」のトレードオフをパラメータ β で調整する
```

**暗号のパラメータ（次元・鍵長）は「この次元・このブロックサイズでは BKZ が
現実的な時間で解けない」という見積もりから逆算して決められる。** アルゴリズム自体の
動作トレースは深掘りキュー行き（[README](./README.md) 参照）。

---

## 耐量子性の根拠

RSA・DH を破る Shor のアルゴリズムは、**周期を見つける問題**（素因数分解・離散対数）に
特化した量子アルゴリズムである
（[`../03_number-theory/05_hard-problems.md`](../03_number-theory/05_hard-problems.md)）。
格子問題は Shor が利用する周期的・群構造を持たないため、**Shor は格子問題に直接は効かない**。

⚠️ ここは慎重な言い方が必要——「量子コンピュータでも絶対に解けない」とは**言えない**。
正確には**「現時点で格子問題を効率的に解く量子アルゴリズムは知られていない」**ということであり、
将来発見される可能性を否定する証明があるわけではない。

## 演習（解答つき）

1. 厳密 SVP と近似 SVP（γ-SVP）の違いを述べよ。暗号が使うのはどちらか。
2. 「良い基底＝秘密鍵」になりうる理由を、[01](./01_lattices-and-bases.md) の内容を踏まえて述べよ。
3. Shor のアルゴリズムが格子問題に直接は効かない理由を一言で述べよ。

<details><summary>解答</summary>

1. 厳密 SVP は `λ₁` そのものを実現するベクトルを求める問題で、（ランダム化還元のもとで）
   NP困難であることが知られている。近似 SVP（γ-SVP）は `λ₁` の `γ` 倍以内の長さの
   ベクトルで妥協する緩和版で、暗号が安全性の根拠にするのは**近似版**——
   ただし多項式近似率での近似版は NP困難とは知られていない。
2. 良い基底（短く直交に近い）を持つ者は SVP/CVP に近い答えを効率的に計算できるが、
   悪い基底しか持たない者はまず良い基底を作り直す（簡約する）こと自体が難しい。
   両者に与える基底を変えるだけで「解ける人」と「解けない人」を作り分けられるため、
   良い基底を秘密に持つ者だけが計算できる、というトラップドアが成立する。
3. Shor のアルゴリズムは素因数分解・離散対数のような**周期を見つける問題**に特化しており、
   格子問題はそのような周期的構造を持たないため。

</details>

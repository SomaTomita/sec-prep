# 01. Vernam 暗号とワンタイムパッド

> 親: [README](./README.md) ｜ 次: [02 鍵長の問題](./02_key-length-problem.md) ｜ 層: 深掘り(Layer 2)

**この1ページで分かること**

- XOR（排他的論理和）の 3 性質だけで暗号化と復号が同じ操作になる理由
- ワンタイムパッド (OTP) が「計算能力無限の敵にも破れない」ための 3 条件
- 鍵を 2 度使うと `C₁ ⊕ C₂ = P₁ ⊕ P₂` で鍵が消える two-time pad の失敗

## 動機

暗号の最小単位は「平文に乱数を重ねて隠す」こと。**Vernam 暗号**（1917 年、電信機向け）はそれを 1 行でやる。

```
平文 ⊕ ランダムビット列 = 暗号文
```

条件さえ満たせば**理論上破れない**（＝ワンタイムパッド, OTP）。まず 4 bit で 1 回やってみる。

```
平文   1 0 1 1      暗号化: 桁ごとに「違えば 1・同じなら 0」
鍵     0 1 1 0
      ───────
暗号文 1 1 0 1      復号: 暗号文に同じ鍵をもう一度重ねる → 1 0 1 1 に戻る
```

この「違えば 1」の演算が XOR。以下で性質を確かめ、8 bit・鍵の条件へ一般化する。

## XOR とは何をする演算か

XOR（排他的論理和, `⊕`）は「2つのビットが**違えば 1**、**同じなら 0**」を返す。

| `a` | `b` | `a ⊕ b` | 言い換え |
|---|---|---|---|
| 0 | 0 | 0 | 同じ → 0 |
| 0 | 1 | 1 | 違う → 1 |
| 1 | 0 | 1 | 違う → 1 |
| 1 | 1 | 0 | 同じ → 0 |

暗号で効いてくる性質は次の3つだけ。

- `a ⊕ a = 0`（自分自身と XOR すると消える）
- `a ⊕ 0 = a`（0 は何もしない）
- `(a ⊕ b) ⊕ c = a ⊕ (b ⊕ c)`（結合律 —— 好きな順序でまとめてよい）

## 手計算での例

```
Plaintext:  1 0 1 1 0 0 1 0
Random:     0 1 1 0 1 1 0 1
            ─────────────── XOR（桁ごとに独立、繰り上がりなし）
Ciphertext: 1 1 0 1 1 1 1 1
```

復号も**まったく同じ操作**をする。

```
Ciphertext: 1 1 0 1 1 1 1 1
Random:     0 1 1 0 1 1 0 1
            ─────────────── XOR
Plaintext:  1 0 1 1 0 0 1 0   ← 元に戻った
```

戻る理由は、上の3性質を並べるだけで出る。

```
C ⊕ K = (P ⊕ K) ⊕ K = P ⊕ (K ⊕ K) = P ⊕ 0 = P
```

## 動かして確かめる

「1ビット進む」で暗号化を1桁ずつ計算し、そのまま復号まで進む。
鍵をランダムにしても、平文を書き換えても、必ず `P′` は `P` と一致する。

<div class="stream-lab" data-lab="xor-pad" data-plaintext="10110010" data-key="01101101"></div>

見てほしいのは次の2点。

1. **各桁は独立**。3桁目の計算に1桁目の結果は一切関係しない（だから並列化できる）。
2. **暗号化と復号が同じ回路**。XOR を1個持っていれば両方できる。

## 何が「完全に安全」なのか

鍵 `K` が次の 3 条件を満たすとき**ワンタイムパッド (OTP)** と呼び、**情報理論的に安全**（計算能力が無限の攻撃者にも破れない）になる。

| 条件 | 破ったときに起きること |
|---|---|
| 鍵が平文と**同じ長さ** | 足りない分を使い回すことになり、下の「鍵の再利用」に落ちる |
| 鍵が**一様ランダム** | 偏りが統計的に平文へ漏れる |
| 鍵を**二度使わない** | `C₁ ⊕ C₂ = P₁ ⊕ P₂` となり鍵が消え、平文同士の関係が露出する |

3つ目が有名な **two-time pad の失敗**。同じ鍵で暗号化した2つの暗号文を XOR すると、

```
C₁ ⊕ C₂ = (P₁ ⊕ K) ⊕ (P₂ ⊕ K) = P₁ ⊕ P₂
```

鍵が消え、**平文同士の XOR** が攻撃者の手に入る。自然言語や形式が既知のデータなら両方の平文を復元できる。

なぜこの3条件で「完全」と言えるのかの証明は

に本体があるのでそちらを参照（ここでは重複させない）。

## 演習

1. `P = 11001010`、`K = 10101010` のとき `C` を求めよ。さらに `C ⊕ K` が `P` に戻ることを確かめよ。
2. 攻撃者が `C = 11011111` を手に入れた。鍵が一様ランダムな 8 ビットだとすると、
   平文としてありうるビット列は何通りか。
3. 同じ鍵 `K` で `P₁` と `P₂` を暗号化してしまった。攻撃者が `C₁` と `C₂` の両方を持っているとき、
   `K` を知らなくても計算できる値は何か。

<details><summary>解答</summary>

1. `C = 11001010 ⊕ 10101010 = 01100000`。
   戻すと `01100000 ⊕ 10101010 = 11001010 = P`。
2. **256 通り（2⁸ 通りすべて）**。任意の平文候補 `P′` に対して `K′ = C ⊕ P′` という鍵が
   ちょうど1つ存在し、それが選ばれた確率はどれも等しく 1/256。つまり暗号文を見ても
   平文について何ひとつ絞り込めない —— これが「完全秘匿」の意味。
3. `C₁ ⊕ C₂ = P₁ ⊕ P₂`、すなわち**2つの平文の XOR**。鍵は打ち消し合って消える。
   ここから片方の平文を推測できれば、もう片方も即座に確定する。

</details>

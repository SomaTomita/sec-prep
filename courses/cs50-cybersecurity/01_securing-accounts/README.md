# 01. アカウントを守る

入口はほぼ例外なく「ユーザ名 + パスワード」で、そこが最も広く狙われる。パスワードが破られる仕組みを**数え上げ**で定量化し、逆算して防御（長さ・多要素・レート制限・パスワードマネージャ・パスキー）を組み立てる。貫く主題は**可用性とのトレードオフ** — 安全にするほど使いにくくなり、人間は付箋に書き出す。

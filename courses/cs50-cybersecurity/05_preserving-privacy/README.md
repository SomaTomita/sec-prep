# 05. プライバシーを保つ

ここまでは「A と B の間に第三者を入れない」話。この講義は**そもそも B に知られたくない情報**を守る。暗号化はプライバシーを保証しない — TLS が完璧でも、履歴はサーバのログに残り、Referer は出自を漏らし、ブラウザ設定の組み合わせで個人が識別され、DNS は行き先を平文で告げる。その漏洩経路を一つずつ潰す。

# 02. データを守る

前講義はパスワードを「使う側」、ここは**受け取って保管する側**から始めてハッシュ・ソルトを導入し、暗号学全体（共通鍵・公開鍵・デジタル署名）へ広げる。この 3 部品は以降すべての土台 — TLS も証明書もパスキーも Tor も、突き詰めれば「ハッシュ・暗号化・署名」の組み合わせでしかない。

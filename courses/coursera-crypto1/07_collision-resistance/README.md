# 07. 衝突耐性

衝突耐性ハッシュ関数を導入する。定義と応用(小さい MAC を大きい MAC に拡張する・鍵なしのファイル完全性)、そして任意のハッシュ関数に効く汎用攻撃=誕生日攻撃。

> ビデオ1はこのモジュールの途中(誕生日攻撃の確率評価)で終わる。続き(Merkle–Damgård・HMAC)はビデオ2で扱う。

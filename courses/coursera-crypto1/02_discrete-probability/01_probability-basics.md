# 01. 確率の基礎

> 親: [README](./README.md) ｜ 前: [README](./README.md) ｜ 次: [XOR と誕生日パラドックス](./02_xor-and-birthday-paradox.md) ｜ 出典: Crypto I ビデオ1 (0:45:19–1:03:21)

暗号の安全性は「攻撃者が鍵を当てられる確率」のような命題で語られる。その土台となる離散確率を、有限集合上の分布・事象・確率変数という最小限の道具で整理する。

---

## 分布 — 有限集合上の重みづけ

有限集合 `U`(暗号では典型的にビット列全体 `{0,1}^n`、要素数 `|U| = 2^n`)を考える。`U` 上の**確率分布** `P` とは、各元 `x ∈ U` に重み `P(x) ∈ [0,1]` を割り当て、その総和が 1 になるもの:

```
P(x) ∈ [0, 1]   かつ   Σ_{x∈U} P(x) = 1
```

分布は長さ `|U|` の実ベクトルとみなせる。各成分が重み、成分の和が 1 のベクトルである。

代表的な 2 つ:

- **一様分布 (uniform)**: すべての元が同じ重み `P(x) = 1/|U|`。暗号で鍵をランダムに選ぶ状況のモデル。
- **点分布 (point)**: ある 1 点 `x0` に全重み `P(x0) = 1`、他は 0。決定的に 1 つの値を取る状況。

---

## 事象 (event) と確率

**事象** `A` とは `U` の部分集合 `A ⊆ U`。事象 `A` が起こる確率は、含まれる元の重みの総和:

```
Pr[A] = Σ_{x∈A} P(x)     （0 ≤ Pr[A] ≤ 1）
```

**例**: `U = {0,1}^8`(256 個)の一様分布で、事象 `A =「下位 2 bit が 11」`。下位 2 bit を固定すると残り 6 bit は自由なので `|A| = 2^6 = 64`。よって `Pr[A] = 64/256 = 1/4`。

---

## union bound(合併上界)

2 つの事象 `A1, A2` について、和事象の確率は各確率の和で上から抑えられる:

```
Pr[A1 ∪ A2] ≤ Pr[A1] + Pr[A2]
```

`A1` と `A2` が**互いに素**(`A1 ∩ A2 = ∅`)のときだけ等号が成り立つ。証明の直感は「重なった部分を 2 回数えてしまうぶんだけ右辺が大きくなる」こと。安全性証明では「複数の失敗事象のどれかが起きる確率」を、各失敗確率の和で雑に上から抑える道具として頻出する。

**例**: 上の `U = {0,1}^8` 一様分布で、`A1 =「下位 2 bit = 11」`、`A2 =「上位 2 bit = 11」`。どちらも確率 `1/4` なので `Pr[A1 ∪ A2] ≤ 1/4 + 1/4 = 1/2`。実際は両方 11 になる元(中間 4 bit が自由で 16 個)が重複するため、真の値は `(64 + 64 − 16)/256 = 112/256 = 0.4375 < 0.5`。互いに素でないので等号は成り立たない。

---

## 確率変数 (random variable)

**確率変数** `X` とは、`U` から値域 `V` への関数 `X : U → V`。`U` 上の分布は `V` 上の分布を**誘導**する:

```
Pr[X = v] = Pr[ { x ∈ U : X(x) = v } ]
```

**例**: `X = lsb(y)`(最下位ビットを取り出す関数、`V = {0,1}`)。入力 `y` が `{0,1}^n` 上の一様分布なら、最下位ビットが 0 の元と 1 の元はちょうど半々なので `Pr[X = 0] = Pr[X = 1] = 1/2`。

特に、`U` 上の一様分布に従う確率変数を**一様確率変数**と呼び、`r ←$ U`(`r` を `U` から一様ランダムに取る)と書く。

---

## 乱択アルゴリズム

暗号のアルゴリズムの多くは**乱択 (randomized)**、すなわち通常の入力 `m` に加えて、内部で毎回新たに一様サンプルする暗黙のランダム入力 `r ←$ {0,1}^n` を使う:

```
y ← A(m ; r)          r は毎回サンプルし直す
```

`r` がランダムなので、出力 `y = A(m ; r)` も確率変数となり、値域上の分布を定める。決定的アルゴリズムは `r` を使わない(常に同じ出力を返す)特別な場合とみなせる。鍵生成や暗号化の「ランダム性」はこの `r` に由来する。

---

## 問題

**Q1.** `U = {0,1}^2` の 4 元に重み `(1/2, 1/8, 1/4, 1/8)` を割り当てた。これは分布か。

<details><summary>解答</summary>

各値は `[0,1]` に入り、総和は `1/2 + 1/8 + 1/4 + 1/8 = 4/8 + 1/8 + 2/8 + 1/8 = 8/8 = 1`。よって正しい分布である(ただし一様ではない)。

</details>

**Q2.** `U = {0,1}^8` の一様分布で、事象「上位 2 bit が 11」の確率は。

<details><summary>解答</summary>

上位 2 bit を固定すると残り 6 bit が自由なので該当は `2^6 = 64` 個。`64/256 = 1/4`。

</details>

**Q3.** union bound `Pr[A1 ∪ A2] ≤ Pr[A1] + Pr[A2]` で等号が成り立つのはどんなときか。

<details><summary>解答</summary>

`A1 ∩ A2 = ∅`(互いに素)のとき。重複がないので和事象の重みがちょうど各重みの和になる。重なりがあると右辺が重複ぶんだけ大きくなり、真の値は小さくなる。

</details>

**Q4.** `r1, r2` は `{0,1}^2` 一様分布の 2 bit。各 bit を整数 0/1 とみて `X = r1 + r2`。`Pr[X = 2]` は。

<details><summary>解答</summary>

`X = 2` は両ビットが 1、すなわち `r = 11` のときだけ。4 通り中 1 通りなので `Pr[X = 2] = 1/4`。(ちなみに `Pr[X=0]=1/4`, `Pr[X=1]=1/2`。)

</details>

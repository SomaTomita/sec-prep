# 12. 公開鍵暗号(RSA)

公開鍵暗号の安全性を定義し、落とし戸付き関数から構成し、その代表例である RSA を組み立てる。

このモジュールで最も繰り返される警告は一つ: **RSA は暗号方式ではなく関数である**。メッセージに直接 RSA を適用する「教科書 RSA」は必ず破れる。実際に使うのは ISO 標準や OAEP のような、乱数化とパディングを伴う正しい包み方の方である。後半では PKCS#1 v1.5 に対する Bleichenbacher 攻撃、鍵長を削る Wiener 攻撃、そして実装側の側チャネル攻撃を見る。

# 05. ワンタイム MAC と Carter–Wegman

> 親: [README](./README.md) ｜ 前: [パディングと CMAC/PMAC](./04_padding-and-cmac-pmac.md) ｜ 次: [07. 衝突耐性](../07_collision-resistance/README.md) ｜ 出典: Crypto I ビデオ1 (7:49:47–7:58:12)

PRF ベース MAC は堅牢だが、ブロック暗号を何度も呼ぶので長いメッセージでは重い。**1 メッセージにしか使わない**と割り切れば、情報理論的に安全で、しかも桁違いに速い MAC が作れる。

---

## ワンタイム MAC(多項式構成)

鍵を 1 メッセージにしか使わない前提。大きな素数 `q`(例 `q = 2^128 + 51`)を選び、鍵は 2 つの値 `(a, k) ∈ {1,…,q}²`。メッセージをブロックに分けて `Z_q` の係数列 `m = (m[1],…,m[L])` とみなし、多項式で評価する:

```
S( (a,k), m ) = a + m[1]·k + m[2]·k² + … + m[L]·k^L   mod q
              = a + P_m(k)     mod q       （P_m は m から作った多項式）
```

- `+a mod q` が **ワンタイムパッド**の役割を果たし、1 回だけなら出力を一様ランダムに隠す → **情報理論的に安全**(計算量の仮定すら不要)。偽造成功確率は `Adv ≤ L/q` で、`q` が巨大なら無視できる。
- 乗算主体で PRF より **ずっと高速**。
- **2 回使うと鍵が割れる。** 2 つの `(m, tag)` から `a` と `k` に関する連立方程式が立ち、`k` が求まる。以後は任意メッセージのタグを計算でき、偽造し放題。だから「ワンタイム」。

---

## Carter–Wegman MAC — ワンタイム MAC を多数回使えるように

ワンタイム MAC `S` の速さを活かしつつ、多数のメッセージに使えるようにする構成。重い PRF `F` は **短い乱数 `r` にだけ** 適用する:

```
CW( (k1,k2), m ) = ( r,  F(k1, r) ⊕ S(k2, m) )     r は毎回新規の乱数（nonce）
```

```
長いメッセージ m ─→ 速いワンタイム MAC S(k2,·) ─┐
短い r ─→ 重い PRF F(k1,·) ─────────────────⊕─→ タグの後半
出力タグ = ( r , F(k1,r) ⊕ S(k2,m) )
```

- **速い部分(`S`)が長いメッセージを処理**し、遅い部分(`F`)は短い `r` だけ。だから大きいメッセージを高速に MAC できる。
- `r` が毎回変わるので、`S(k2,m)` が `F(k1,r)` という「その回限りのパッド」で隠され、`S` を実質ワンタイムに使える。
- **これは乱択 MAC(PRF ではない)。** 同じ `m` でも `r` ごとに異なる有効タグが無数に存在する。

### 検証

タグ `(r, t)` を受け取ったら:

```
V( (k1,k2), m, (r,t) ):
  s = t ⊕ F(k1, r)         パッドを外す
  accept ⟺ s == S(k2, m)   ワンタイム MAC 側で照合
```

---

## 問題

**Q1.** ワンタイム多項式 MAC を同じ鍵で 2 回使うと、攻撃者は何を得るか。

<details><summary>解答</summary>

2 つの `(m, tag)` が `tag = a + P_m(k) mod q` を満たす。2 本の式から `a` を消去して `k` を解ける(多項式の差が `k` の方程式になる)。`k` と `a` が判明すれば任意メッセージの正しいタグを計算でき、以後いくらでも偽造できる。

</details>

**Q2.** Carter–Wegman MAC の検証アルゴリズムを書け。

<details><summary>解答</summary>

タグ `(r, t)` に対し `s = t ⊕ F(k1, r)` を計算し、`s == S(k2, m)` なら受理、違えば拒否。`r` から同じパッド `F(k1,r)` を再生してワンタイム MAC 側の値と照合する。

</details>

**Q3.** Carter–Wegman MAC が PRF(決定的 MAC)でない理由は。

<details><summary>解答</summary>

タグに毎回新しい乱数 `r` を含み、`(r, F(k1,r)⊕S(k2,m))` は `r` の選び方だけ多数の有効タグを持つ。同じ `m` に対しタグが一意でないので決定的な PRF ではなく、乱択 MAC に分類される。

</details>

**Q4.** ワンタイム MAC の `+a mod q` は、OTP(ワンタイムパッド)の何に対応するか。

<details><summary>解答</summary>

`+a` は多項式評価値 `P_m(k)` に一様ランダムな `a` を足して隠す操作で、OTP でメッセージに鍵を XOR して隠すのと同じ役割。だから 1 回なら情報理論的に安全だが、`a` を再利用すると two-time pad と同様に安全性が崩れ、鍵が漏れる。

</details>

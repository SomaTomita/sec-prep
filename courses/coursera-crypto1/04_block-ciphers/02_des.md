# 02. DES

> 親: [README](./README.md) ｜ 前: [01. ブロック暗号と PRF/PRP](./01_block-cipher-and-prf-prp.md) ｜ 次: [03. 総当たり攻撃と 3DES](./03_exhaustive-search-and-3des.md) ｜ 出典: Crypto I ビデオ1 (4:19:04–4:41:25)

最初に広く使われたブロック暗号 DES を通して、「可逆でない関数から可逆な暗号を組む」**Feistel 構造**を学ぶ。復号回路が暗号化回路と同じになり、ハード実装で有利。

**この1ページで分かること**

- Feistel: 可逆でない `f` から可逆な写像を機械的に作る。逆変換は鍵を逆順に適用するだけ
- Luby–Rackoff: 安全な PRF を独立 3 鍵・3 ラウンドの Feistel に入れると安全な PRP
- DES = 16 ラウンド Feistel。S ボックスが唯一の非線形部品で、線形なら全滅する

---

## 歴史

IBM の Horst Feistel が設計した **Lucifer**（鍵 128 bit）を NBS（現 NIST）が公募・標準化し、1976 年に **DES**（鍵 56 bit・ブロック 64 bit）が制定された。鍵を 128 → 56 bit に削った点が後年の弱点となり、1997 年に総当たりで陥落、AES へ移行する。

---

## Feistel ネットワーク

任意の関数 `f_1, …, f_d`（**可逆でなくてよい**）から可逆な関数を作る枠組み。入力を左右 `(L,R)` に分け、各ラウンドで:

```
L_i = R_{i-1}
R_i = L_{i-1} ⊕ f_i(R_{i-1})
```

```
      L_{i-1}                 R_{i-1}
         │                       │
         │                       ├──────────────┐
         │                 ┌─────▼─────┐        │
         │                 │  f_i(k_i) │        │
         │                 └─────┬─────┘        │
         └────────► (⊕) ◄────────┘              │
                     │                          │
                     ▼                          ▼
                    R_i = L_{i-1}⊕f_i(R_{i-1})  L_i = R_{i-1}
```

**逆変換**は `R_{i-1} = L_i`、`L_{i-1} = R_i ⊕ f_i(L_i)`。`f_i` を順方向に評価するだけでよい。同じ回路で**鍵を逆順に適用**すれば復号になる。

---

## Luby–Rackoff 定理 (1985)

> **安全な PRF** を 3 ラウンド Feistel に**独立な 3 鍵**で使うと、**安全な PRP** になる。

Feistel が「可逆」だけでなく「擬似ランダム置換として安全」を与える理論的裏づけ。2 ラウンドでは安全にならない。

---

## DES 本体

Feistel を **16 ラウンド**。56 bit 鍵から **48 bit のラウンド鍵を 16 個**作り、各ラウンドの関数 `F` に与える。

```
R (32 bit) ─[拡大 E]→ 48 bit ─(⊕ k_i)→ 48 bit
   ─[S ボックス 8 個]→ 32 bit ─[置換 P]→ 32 bit
```

| 部品 | 働き |
|------|------|
| 拡大 E | 32 bit → 48 bit に広げ、ラウンド鍵と XOR |
| S ボックス ×8 | 各 6 bit → 4 bit のルックアップ表。**DES 唯一の非線形部品** |
| 置換 P | 出力 32 bit を並べ替える |
| 初期置換・最終置換 | 安全性とは無関係（歴史的・実装上の都合） |

---

## S ボックスが線形だと壊滅する

S ボックスが線形（＝行列演算）なら DES 全体が線形写像 `DES(k,m) = A·m ⊕ B·k` になる。

```
DES(k, m1) ⊕ DES(k, m2) ⊕ DES(k, m3) = DES(k, m1 ⊕ m2 ⊕ m3)
```

真のランダム置換では成り立たないので**識別**でき、約 **832 組**の入出力対から線形代数で鍵 `k` を復元できる。だから S ボックスには「線形写像から遠い」「1 出力が高々 4 入力に対応」などの設計基準が課された。わずかな線形性でも致命傷になることは次章の線形解読で再確認する。

---

## 問題

**Q1.** Feistel の 1 ラウンド `L_i=R_{i-1}, R_i=L_{i-1}⊕f_i(R_{i-1})` の逆変換を、`(L_i,R_i)` から `(L_{i-1},R_{i-1})` の式で書け。

<details><summary>解答</summary>

`R_{i-1} = L_i`、`L_{i-1} = R_i ⊕ f_i(R_{i-1}) = R_i ⊕ f_i(L_i)`。`f_i` を評価するだけでよく、逆写像は不要。だから `f_i` が可逆でなくても全体は可逆になる。

</details>

**Q2.** 安全な PRF から安全な PRP を作るのに、Feistel は何ラウンド必要か。

<details><summary>解答</summary>

Luby–Rackoff 定理より、独立な 3 鍵での **3 ラウンド**。2 ラウンドでは安全な PRP にならない。

</details>

**Q3.** S ボックスが線形なとき `DES(k,m1) ⊕ DES(k,m2) ⊕ DES(k,m3)` は何に等しくなるか。

<details><summary>解答</summary>

`DES(k, m1 ⊕ m2 ⊕ m3)`。DES 全体が線形になるため。真のランダム置換ではこの等式は成り立たないので識別器になり、約 832 組の入出力対から鍵も復元できる。

</details>

**Q4.** DES のラウンド鍵は全部で何 bit か。

<details><summary>解答</summary>

48 bit のラウンド鍵が 16 個なので `48 × 16 = 768` bit（これらは 56 bit のマスター鍵から鍵展開で導かれる）。

</details>

# 04. 高度な攻撃

> 親: [README](./README.md) ｜ 前: [03. 総当たり攻撃と 3DES](./03_exhaustive-search-and-3des.md) ｜ 次: [05. AES](./05_aes.md) ｜ 出典: Crypto I ビデオ1 (5:00:51–5:17:01)

鍵が十分長くても暗号は破られる。**アルゴリズムの数学的弱点**（線形解読）と、**実装の漏れ**（サイドチャネル・フォールト）、そして**未来の脅威**（量子）——総当たり以外の攻撃面を俯瞰する。教訓は一貫して「暗号は自分で実装するな、標準ライブラリを使え」。

---

## 実装攻撃（サイドチャネル）

暗号の数式ではなく、動く**物理的な機械**から鍵が漏れる。

- **タイミング攻撃**: 処理時間が鍵やデータに依存すると、時間の測定から鍵を推定できる。
- **電力解析**: 消費電力の波形に、DES の初期/最終置換や 16 ラウンドの構造がそのまま見える。**差分電力解析 (DPA)** はさらに多数の波形を統計処理して鍵ビットを抽出する。
- **キャッシュ攻撃**: マルチコア環境で、鍵を持たない**別コアのプロセス**がキャッシュの使われ方を観測して鍵を盗む。

対策の実務的な結論はシンプル: **暗号を自前実装せず**、OpenSSL 等の実績ある標準ライブラリ（定数時間実装・キャッシュ対策済み）を使う。

---

## フォールト攻撃

暗号処理の**最終ラウンドで計算エラーを故意に誘発**（電圧グリッチ・レーザ照射など）すると、その誤った出力と正しい出力の差分から鍵が漏れる。

対策: **出力前に検算する**。同じ計算を複数回行って結果が一致することを確認する（多数決）。一致しなければ出力せずにエラーとする。

---

## 線形解読法 (Matsui 1993)

Biham と Shamir の差分解読法の系譜に連なる、DES への統計的攻撃。松井充 (Matsui) が発見した。DES の第 5 S ボックスに残る**わずかな線形性**を突く。

平文 `m`・暗号文 `c`・鍵 `k` の、あるビット部分集合の XOR に次の相関がある。

```
(m のビット集合の XOR) ⊕ (c のビット集合の XOR) = (k のビット集合の XOR)
     が成り立つ確率 = 1/2 + ε        （ε = 1/2^21）
```

真にランダムなら確率はちょうど `1/2`（`ε=0`）のはず。この偏り `ε` を使い、多数の既知平文・暗号文対で左辺を集計して**多数決**すれば右辺（鍵ビットの XOR）を当てられる。必要な対数は `1/ε^2 = (2^21)^2 = 2^42` 組。これで鍵 14 bit を得て、残り 42 bit を総当たり → **計 ~2^43** で全鍵回復。教訓: **わずかな線形性が致命傷になる**。

---

## 量子攻撃

Grover のアルゴリズムは、鍵空間 `|K|` の探索を `O(√|K|)` に短縮する（総当たりの平方根）。鍵長への影響:

```
DES      : 2^56  →  2^28   （即死）
AES-128  : 2^128 →  2^64   （危うい）
AES-256  : 2^256 →  2^128  （安全）
```

対称鍵は Grover で**実効強度が半分の bit 数**になる。よって**量子時代に備えるなら 256 bit 鍵**（AES-256）を使う。ただし実用的な量子計算機が作れるかは未解決の問題である。

---

## 問題

**Q1.** 線形解読で偏りが `ε = 1/2^21` のとき、鍵ビットを推定するのに必要な既知平文・暗号文対のおおよその数は。

<details><summary>解答</summary>

`1/ε^2 = (2^21)^2 = 2^42` 組。これで 14 bit を復元し、残り 42 bit を総当たりして計 ~2^43。

</details>

**Q2.** Grover のアルゴリズム後の AES-128 と AES-256 の実効強度をそれぞれ答えよ。

<details><summary>解答</summary>

AES-128 → `2^64`（危険水準）、AES-256 → `2^128`（安全）。Grover は探索を `√|K|` にするので鍵の実効 bit 数が半分になる。だから量子時代は 256 bit 鍵。

</details>

**Q3.** サイドチャネル対策を 2 つ挙げよ。

<details><summary>解答</summary>

例: (1) 処理時間を入力・鍵に依存させない**定数時間実装**を使う、(2) 自前実装せず OpenSSL 等の**標準ライブラリ**を使う。他にキャッシュアクセスを鍵非依存にする、電力波形をマスキング/ノイズ付加で撹乱する、なども可。

</details>

**Q4.** 線形解読の教訓を 1 行で述べよ。

<details><summary>解答</summary>

S ボックスに残るわずかな線形性（`1/2 + ε` の偏り）でも、多数の既知平文で多数決すれば鍵が漏れる —— 非線形部品は「ほぼ線形」ですら危険。

</details>

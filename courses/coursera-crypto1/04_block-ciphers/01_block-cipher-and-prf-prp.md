# 01. ブロック暗号と PRF/PRP

> 親: [README](./README.md) ｜ 前: [README](./README.md) ｜ 次: [02. DES](./02_des.md) ｜ 出典: Crypto I ビデオ1 (4:02:29–4:19:04)

ストリーム暗号が「鍵から擬似乱数列を作って XOR する」だったのに対し、ブロック暗号は「固定長ブロックを丸ごと別のブロックへ写す鍵付き置換」である。まずこの写像を抽象化した **PRF / PRP** という2つの道具を定義し、何をもって「安全」と呼ぶかを固める。

---

## ブロック暗号とは

ブロック暗号は `n` bit の入力を `n` bit の出力へ写す**鍵付き関数**で、実装は「鍵展開 → ラウンド関数の反復」という共通形を取る。

```
鍵 k ──[鍵展開]──> k1, k2, …, kd （ラウンド鍵）

m ─> [R(k1,・)] ─> [R(k2,・)] ─> … ─> [R(kd,・)] ─> c
        1ラウンド      2ラウンド            dラウンド
```

代表例（ブロック長 / 鍵長 / ラウンド数）:

| 暗号 | ブロック | 鍵 | ラウンド |
|------|---------|----|---------|
| 3DES (Triple DES) | 64 bit | 168 bit | 48 |
| AES | 128 bit | 128 / 192 / 256 bit | AES-128 は 10 |

ブロック暗号は内部でラウンドを何度も回すため、ストリーム暗号より一般に**遅い**。

---

## PRF と PRP

- **PRF (擬似ランダム関数)** `F: K × X → Y`。鍵 `k` と入力 `x` から `F(k,x)` を**効率的に評価**できればよく、逆写像は不要。
- **PRP (擬似ランダム置換)** `E: K × X → X`。各鍵 `k` について `E(k,·)` が `X` 上の**全単射**で、逆演算 `D(k,·)` も**効率的**に計算できる。

つまり PRP は「`X = Y` かつ可逆」という条件を満たす PRF の**特別な場合**である。ブロック暗号はまさに PRP（暗号化 `E` と復号 `D` が対）。

---

## 「安全」の定義 —— 真の乱数と区別できない

`X → Y` の関数**全体**の集合を `Funs[X,Y]` と書くと、その大きさは

```
|Funs[X,Y]| = |Y|^|X|
```

PRF `F` が定める関数の集合は `S_F = { F(k,·) : k ∈ K }` で、大きさは高々 `|K|`。`|K|` は `|Y|^|X|` に比べ桁違いに小さい（AES-128 なら `2^128` 個 対 `(2^128)!` 個）。

> **安全性**: `Funs[X,Y]` から一様に選んだ**真のランダム関数**と、`S_F` から選んだ関数とを、入力を自由にクエリできる識別器が**区別できない**とき `F` は安全な PRF。区別できる度合い（Adv）が無視できるほど小さいことを要求する。

---

## 1点でも固定すると壊れる（反例）

安全な PRF `F` から `G` を「`G(k,0) = 0`（`x=0` のときだけ強制的に 0）、それ以外は `F(k,x)`」と定義すると、`G` は**安全でない**。

識別器は `x = 0` を1回クエリするだけでよい。真のランダム関数なら出力が 0 になる確率は `1/|Y|` だが、`G` は必ず 0 を返す。よって Adv ≈ `1 − 1/|Y|` ≈ 1 で即座に見破られる。**たった1点を固定しただけでも**安全性は崩壊する。

---

## PRF から PRG を作る

安全な PRF があれば、カウンタを入れるだけで PRG（擬似乱数生成器）になる。

```
G(k) = F(k,0) ‖ F(k,1) ‖ F(k,2) ‖ … ‖ F(k,t)
```

もし `F` が真のランダム関数なら各 `F(k,i)` は独立な真の乱数なので出力は真の乱数列。ゆえに `F` が擬似ランダムなら出力も擬似ランダムになる。各ブロックが独立に計算できるため**並列化でき**、これがカウンタモード（次モジュール）の原型である。

---

## 問題

**Q1.** `X = Y = {0,1}^128` のとき `|Funs[X,Y]|` を指数の式で表せ。

<details><summary>解答</summary>

`|Y|^|X| = (2^128)^(2^128) = 2^(128 · 2^128)`。鍵で選べる `2^128` 個とは比較にならない巨大さで、この差が「有限の鍵で真の乱数を真似る」PRF の意味を与える。

</details>

**Q2.** `G(k,0)=0`、それ以外 `F` と定めた `G` に対する識別器のおおよその Adv は。

<details><summary>解答</summary>

`x=0` を1回クエリし「出力が 0 なら G と判定」。`G` では確率 1、真のランダム関数では確率 `1/|Y|`。よって Adv ≈ `1 − 1/|Y| ≈ 1`。1点固定でも壊れる。

</details>

**Q3.** PRF と PRP の違いを、逆写像の観点で1文で述べよ。

<details><summary>解答</summary>

PRF は評価だけできればよく逆写像を要求しない（`X→Y` の一般の関数）。PRP は `X=Y` の全単射で、効率的な逆演算 `D` を持つ（＝可逆な PRF の特別な場合）。

</details>

**Q4.** `G(k)=F(k,0)‖…‖F(k,t)` が擬似ランダムになる直観を述べよ。

<details><summary>解答</summary>

`F` が真のランダム関数なら異なる入力 `0,1,…,t` への出力は独立な真の乱数なので `G(k)` は真の乱数列。安全な PRF はこれと識別不能なので、出力も擬似ランダムになる。

</details>

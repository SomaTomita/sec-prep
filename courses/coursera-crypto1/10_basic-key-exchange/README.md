# 10. 鍵交換の基礎

ここから話題が変わる。これまでは「共通鍵をすでに持っている 2 者」を前提にしてきた。その共通鍵はどこから来るのか、というのがこのモジュールの問いである。

まずオンラインの信頼できる第三者を置く素朴な方式を見て、その限界(第三者が全鍵を知る・常時稼働が必要)を確認する。次に第三者なしの鍵交換を、対称暗号だけで作る試み(Merkle パズル、二次のギャップしか作れない)、そして代数を使う Diffie–Hellman(指数的なギャップ)へ進む。

> このモジュールの鍵交換はすべて**盗聴に対してのみ安全**であり、そのまま実運用してはならない。能動的攻撃者に対する認証付き鍵交換は本コースの範囲外(後半コース)。

# 11. 数論

公開鍵暗号を組み立てるための道具を揃える回。ユークリッドの互除法(紀元前)から始まり、Fermat・Euler・Lagrange(17〜19 世紀)を経て、離散対数と素因数分解という現代の困難性仮定に至る。

読むときの視点は一貫している: **何が効率的に計算でき、何が計算できないと信じられているか**。この境界線の上に公開鍵暗号のすべてが乗っている。

# 05. PRG の安全性の定義

> 親: [README](./README.md) ｜ 前: [実在するストリーム暗号](./04_real-world-stream-ciphers.md) ｜ 次: [意味論的安全性](./06_semantic-security.md) ｜ 出典: Crypto I ビデオ1 (2:38:12–3:03:21)

「PRG が安全」とは何か。統計テストの寄せ集めでは定義にならず、**あらゆる効率的テストで本物の乱数と見分けられない**ことをアドバンテージという 1 つの量で厳密化する。

**この1ページで分かること**

- アドバンテージ `Adv[A, G] = |Pr[A(G(k))=1] − Pr[A(r)=1]|` が「見破り度」の尺度
- 安全な PRG ⟺ 全ての効率的テストで `Adv` が negligible
- Yao の定理: 次ビット予測不可能 ⟺ 安全な PRG

---

## 統計的テスト

**統計的テスト** `A : {0,1}^n → {0,1}`: ビット列を見て「ランダムらしければ 1」を返す判定器。

| テスト | 判定 |
|---|---|
| `A1` | `#0(x) − #1(x)` の絶対値が `10·√n` 以下（0 と 1 が半々） |
| `A2` | `00` ブロックの個数 ≈ `n/4` |
| `A3` | 最長の 0 連続 ≤ `10·log n` |

個別テストをいくつ集めても**定義にはならない**——次のテストで落ちるかもしれない。「あらゆる効率的テスト」を一度に相手にする枠組みが要る。

---

## アドバンテージ (advantage)

テスト `A` が PRG `G` を見破る度合い＝「`G` の出力への反応」と「本物の乱数への反応」の差:

```
Adv[A, G] = | Pr[ A(G(k)) = 1 ] − Pr[ A(r) = 1 ] |
            （k ←$ 鍵空間,  r ←$ {0,1}^n の一様乱数）
```

```mermaid
flowchart LR
    G["G(k)（PRG の出力）"] --> A["テスト A"]
    R["r（本物の一様乱数）"] --> A
    A --> D["Adv = 2 つの世界での出力 1 の確率差"]
```

| `Adv` | 意味 |
|---|---|
| ≈ 0 | `A` は区別できない（`A` にとって `G` は安全） |
| ≈ 1 | 完全に見破っている |

```
A(x) = 0 を常に返す           → Adv = |0 − 0| = 0        （無力なテスト)
「鍵の 2/3 で先頭 bit = 1」の G に対し
A(x) = [ msb(x) = 1 ? 1 : 0 ] → Adv = |2/3 − 1/2| = 1/6  （見破れている)
```

---

## 安全な PRG の定義

```
G が安全な PRG  ⟺  すべての効率的な統計テスト A に対して
                     Adv[A, G] が negligible
```

「効率的」の限定が肝心。計算量無制限を許すと、全鍵を試して `G(k)` を列挙する非効率テストが必ず勝ち、定義を満たす PRG が存在しなくなる。**安全な PRG の存在は未解決**で、証明できれば `P ≠ NP` が従う。現状は「安全と信じられている」構成を使う。

---

## 予測不可能性との等価性 — Yao の定理

```
安全 ⇒ 予測不可能   （対偶: 予測器 A があれば Adv ≥ ε の識別器 B が作れる)
```

予測器 `A`（次ビットを確率 `1/2+ε` で当てる）があれば、「`A` の予測が当たったら 1」を返すテスト `B` を作れる。本物の乱数では的中率がちょうど `1/2` なので `Adv[B,G] ≥ ε`。

**Yao の定理（1982）**は逆も示した:

```
次ビット予測不可能  ⟺  安全な PRG
```

応用: 「最後のビットから最初のビットを計算できる」PRG も、その規則を使う識別器が作れるので**予測可能＝非安全**（どのビットを予測するかは問わない）。

---

## 計算量的識別不可能性

2 つの分布 `P1, P2` が**計算量的に識別不可能** `P1 ≈p P2` ⟺ すべての効率的テスト `A` で `|Pr[A(P1)=1] − Pr[A(P2)=1]|` が negligible。安全な PRG は一言で:

```
G が安全  ⟺  { k ←$ K : G(k) }  ≈p  { r ←$ {0,1}^n }
```

---

## 問題

**Q1.** テスト `A(x) = 1`(常に 1 を返す)の任意の `G` に対する `Adv[A,G]` は。

<details><summary>解答</summary>

`Pr[A(G(k))=1] = 1`、`Pr[A(r)=1] = 1` なので `Adv = |1 − 1| = 0`。常に同じ値を返すテストは何も区別できず無力。

</details>

**Q2.** 鍵の `2/3` で先頭ビットが 1 になる `G` に対し、テスト `A(x) = [msb(x)=1]` の `Adv` を求めよ。

<details><summary>解答</summary>

`Pr[A(G(k))=1] = 2/3`、`Pr[A(r)=1] = 1/2`(一様乱数の先頭ビットは半々)。`Adv = |2/3 − 1/2| = |4/6 − 3/6| = 1/6`。無視できない大きさなのでこの `G` は非安全。

</details>

**Q3.** Yao の定理は何を主張するか。

<details><summary>解答</summary>

PRG について「次ビット予測不可能」と「安全(一様分布と計算量的に識別不可能)」が**同値**であること。予測不可能性を確かめれば安全性が言え、逆も成り立つ。

</details>

**Q4.** 安全な PRG の定義でテストを「効率的」に限定する理由は。

<details><summary>解答</summary>

限定しないと、全鍵を総当たりして `G(k)` の像を列挙する非効率テストが常に `Adv ≈ 1` で勝ち、定義を満たす PRG が存在しなくなるから。現実的に実行できる攻撃者(=効率的テスト)だけを相手にすることで、意味のある安全性になる。

</details>
